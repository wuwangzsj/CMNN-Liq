# 上传说明

这份文件夹就是精简的“主要代码＋方法思路”上传内容，可整体上传。英文首页为 README.md，方法说明为 METHOD.md。

保留：FS与参考态输入、CMNN及主训练函数、A/N/B0/B1等对照、附加约束投影、支持域与条件查询、累计回落审计、参考震级扩展、评分函数。

不包含：1066条案例数据、留出预测、模型权重、历史结果、论文Word、绘图排版脚本、完整实验调度及本机环境。因此不称为“完整可复现数据包”。data/input_schema.csv 只是输入字段表头。

代码来自现有研究脚本。主要整理动作是摘出核心函数、改成本地模块引用、删除硬编码路径和无关实验分支。SOURCE_INDEX.json 记录来源文件与源文件哈希；check_core.py 只进行代数和数值检查，不训练模型。

模型M的训练入口是 training.Repaired；cmnn.CMNN.fit 为原训练封装保留的初始化接口，不要单独用它替代论文训练过程。固定配置M0与内层选择M不能混用。先看 README.md 的文件导读，再看 METHOD.md 的公式与流程。

原数据库仍引用 DOI：10.17632/rmjnghdrbv.3，不将其重新标为本项目自有数据。当前未替作者指定开放许可证；上传时可在平台选择并补充。已发表论文引用及仓库链接在确定后填写。
